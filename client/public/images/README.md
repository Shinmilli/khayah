# 이미지 폴더

사이트에서 실제로 쓰는 이미지는 모두 `client/public/images/` 아래에 둡니다.  
아카이브(`20170227_khayah_..._archive/images/`) 원본은 **복사(복제)** 해서 사용하고, 원본 폴더는 그대로 둡니다.

## 구조

| 경로 | 용도 |
|------|------|
| `banners/` | 페이지 히어로(PageHero) 배경 |
| `business/` | 국내·해외 사업 본문 이미지 |
| `Home/slider/` | 홈 히어로·아카이브 슬라이더 원본 복제 |
| `Home/parteners/` | 협력기관 로고 |
| `Khayah/` | 카야 소개(가치 버블, 조직도 등) |
| `donor-guide/` | 후원 안내 스크린샷 |
| `logo/` | 로고 |
